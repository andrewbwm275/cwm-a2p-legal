# CWM A2P crawlable legal pages

Static HTML so TCR/Twilio can read STOP/HELP and the mobile-number non-sharing statement without executing JavaScript.

Live www.carwashmgmt.com is still a Base44 SPA, so `/privacy-policy` and `/terms-and-conditions` there are not crawler-visible. These files are the campaign `PrivacyPolicyUrl` and `TermsAndConditionsUrl`.
